# 📊 YouTube Data Analysis

## 🔍 Project Overview
This project explores YouTube video engagement and viewer behavior using real-world data. I applied data analysis and natural language processing techniques to uncover patterns in sentiment, trending content, category performance, and how title formatting influences engagement.

My goal is to strengthen my skills in data analytics and storytelling — delivering insights that could help content creators, marketers, and analysts understand what drives success on YouTube.

---

## ✅ Key Insights
- 🎵 **Music** category dominates in likes and audience engagement  
- ❤️ Comment sentiment is **largely positive**, with emojis like 😂 😍 ❤️ being the most used  
- 🔥 Trending videos attract more expressive emotions and interaction  
- ✍️ Title formatting (e.g., punctuation) shows a **minor but noticeable** impact on engagement  
- 💬 Engagement rates are **high** — audiences interact strongly with popular content  

---

## 🧠 Analytics Performed
- Sentiment Analysis using VADER  
- WordCloud and keyword frequency analysis  
- Emoji sentiment + engagement review  
- View-to-like/comment engagement ratio study  
- Category and trending performance visualizations  
- Title structure influence check
